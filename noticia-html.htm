¿Qué es HTML y para qué sirve?

10 de noviembre de 2026 · Tecnología

HTML son las siglas de HyperText Markup Language. Es un lenguaje de marcado que permite definir la estructura y el contenido de una página web.

¿Qué podemos hacer con HTML?

Podemos organizar textos mediante títulos y párrafos, añadir enlaces a otras páginas, insertar imágenes y crear listas, tablas y formularios.

La estructura básica

Un documento HTML incluye información para el navegador dentro de la sección head y el contenido visible de la página dentro de body.

HTML es una base fundamental para comenzar a aprender desarrollo web.
