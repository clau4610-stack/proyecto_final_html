Desarrollo web desde cero

Área: Desarrollo web

Nivel: Inicial

Descripción del curso

En este curso aprenderás los fundamentos de HTML, el lenguaje utilizado para estructurar el contenido de las páginas web. Crearás documentos con títulos, párrafos, enlaces, imágenes, listas, tablas y formularios.

Contenido

  1. Introducción a la web y a HTML.
  2. Estructura básica de un documento HTML.
  3. Textos, enlaces e imágenes.
  4. Listas, tablas y formularios.
  5. Etiquetas semánticas y estructura de una web.
